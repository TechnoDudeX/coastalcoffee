# Coastal Coffee · قهوة الساحل

Driveway pickup ordering site — weekdays 6–9 AM.

- `index.html` — the full site, self-contained (open it directly or host it anywhere).
- `assets/` — logo files (navy, cream, animated).

## Deploy
Live at https://coastalcoffee.netlify.app — Netlify auto-deploys every push to `main` (no build step; see `netlify.toml`).
